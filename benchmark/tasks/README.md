# Tasks

The `Q1/` through `Q200/` directories contain task descriptions and object references. [index.csv](index.csv) lists scene labels, rule IDs, duration, and action budget. [task_source_zh.md](task_source_zh.md) preserves the original task wording and intervention descriptions.

Task instructions are provided in their original language. Public records include instructions, object prim paths, and constraint descriptions. Source IDs and simulator prim paths retain their original spelling.
