# Tasks

The `Q1/` through `Q200/` directories contain the public task records from the archived candidate. [index.csv](index.csv) lists scene labels, rule IDs, duration, and action budget. [task_source_zh.md](task_source_zh.md) preserves the original task wording and intervention descriptions.

Task text remains in its source language to preserve the evaluated instructions. Public records include instructions, object prim paths, and constraint descriptions. They are task descriptions rather than a complete executable scene/rubric bundle. Source IDs and simulator prim paths retain their original spelling.
